# Pixelgruppe
200x200, bis 30 Teilnehmer, feste Farben, 1 Pixel/5 Sekunden, Live-Updates, Login und Admin-Bereich.

Zum lokalen Testen: Node.js installieren, im Ordner `npm install` und danach `npm start`.
Vor dem Start ein Admin-Passwort setzen: Windows PowerShell `$env:ADMIN_PASSWORD="DEIN_PASSWORT"; npm start`.
